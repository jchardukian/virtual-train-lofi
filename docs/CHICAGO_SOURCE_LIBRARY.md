# Chicago source library

Audit of commercially usable Chicago footage reachable from the build
machine. Every clip below was downloaded, probed with ffprobe and viewed as
frames. "Chicago?" is my visual identification, not a statement from the
uploader unless the title says so. Authors marked (unconfirmed) come from
search snippets, not the clip page, because pexels.com pages do not load
from this machine. **Re-check each page and licence before publishing.**

Licences: Pexels License and Mixkit Free License both allow commercial use
